Arc DevKit is an open-source Python toolkit for building, debugging, and interacting with applications on **Arc Mainnet** — Circle's EVM-compatible Layer 1, where USDC is the gas token and block finality is sub-second thanks to Malachite consensus. Arc Testnet remains fully supported for development.

## What is Arc?

**Arc** is an L1 blockchain created by Circle (creators of USDC), designed specifically for programmable payments and autonomous economic agents. Mainnet launched **2026-09-16**.

| Feature | Detail |
|---|---|
| **EVM-compatible** | Solidity, web3.py and ethers.js work without modification |
| **USDC as gas** | No ETH required — USDC is the native gas token (18 decimals), also exposed as a synchronized ERC-20 view (6 decimals) |
| **Malachite consensus** | Sub-second block finality |
| **Circle Agent Stack** | Native infrastructure for economic AI agents |
| **Mainnet** | Chain ID `5042` · RPC: `https://rpc.mainnet.arc.io` · Explorer: `https://explorer.arc.io` |
| **Testnet** | Chain ID `5042002` · RPC: `https://rpc.testnet.arc.io` · Explorer: `https://explorer.testnet.arc.io` |

## Why Arc DevKit?

Building on Arc exposes you to a series of practical friction points that Arc DevKit resolves:

- **No manual network setup**: chain ID, RPC, explorer, and contract addresses (USDC, EURC, CCTP, Gateway) are pre-configured and sourced for both mainnet and testnet — see [Networks](/docs/modules/networks)
- **Gas in USDC**: unlike other EVMs, USDC is both the native gas token (18 decimals) and an ERC-20 (6 decimals) — the DevKit models both correctly and never conflates them
- **PoA Middleware**: Arc runs a permissioned validator model on both networks and requires `ExtraDataToPOAMiddleware` in web3.py
- **Mainnet safety**: the CLI warns and asks for confirmation before broadcasting real-fund transactions on mainnet
- **Economic agents**: Arc was designed for AI agents — the DevKit provides ready-made base classes
- **Complex debugging**: reverted EVM transactions have encoded error messages; the DevKit decodes and explains them in natural language via AI

## Modules

```
arc_devkit/
├── copilot/         Dev Copilot — AI with built-in Arc context
├── agents/          Payment Agent, Monitor Agent, Async Monitor,
│                    identity.py + jobs.py (ERC-8004/8183 agentic economy)
├── debugger/        Tx Debugger — decode and analyze transactions
├── analytics/       Portfolio Analyzer — balance, history, score
├── stablecoins/     StablecoinToken — USDC and EURC (usdc/ kept as a shim)
├── client.py        Arc facade — Arc.mainnet()/Arc.testnet() single entry point
├── health.py        Shared network health check (`arc doctor`)
├── networks.py      Mainnet/testnet network profiles (chain ID, RPC, contracts)
├── paymaster/       Paymaster detection + ERC-4337 helpers
├── bridge/          CCTP — cross-chain USDC bridge
├── oracle/          Price feed client (Chainlink-compatible)
├── privacy/         View-key encryption + confidential transfers
├── contracts/       Utilities for EVM contracts
├── events/          Event Listener — on-chain log polling
├── deploy/          Contract Deployer
├── api/             FastAPI server with SSE and WebSocket
├── mcp_server.py    Arc DevKit's own MCP server — `arcdevkit mcp serve`
└── cli/             CLI `arc` and `arcdevkit`
```

<Callout type="tip" title="Mainnet migration">
  Arc Mainnet launched 2026-09-16 and is Arc DevKit's default network as of v0.9.0. See the full sourced network reference, security guidance, and migration notes in the SDK repository's `docs/mainnet/` directory.
</Callout>

## Requirements

- Python **3.11+**
- An AI provider key for Dev Copilot — Anthropic (default), or Google Gemini / OpenAI / a local Ollama server (see [Dev Copilot](/docs/modules/dev-copilot))
- No RPC URL required to get started — Arc Mainnet (`https://rpc.mainnet.arc.io`) and Arc Testnet (`https://rpc.testnet.arc.io`) both ship with official defaults; set `ARC_RPC_URL` only to use your own provider
