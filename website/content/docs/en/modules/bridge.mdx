`arc_devkit.bridge` implements the **burn → attestation → mint** flow of Circle's Cross-Chain Transfer Protocol (CCTP) V2 — the public standard used to move USDC natively between chains, without wrapping. Arc is CCTP domain 26; TokenMessengerV2/MessageTransmitterV2/TokenMinterV2 addresses are published for both mainnet and testnet (`arc_devkit.networks`).

<Callout type="warning" title="Not yet validated against a live transfer">
  `CCTPBridge` now targets CCTP V2's `depositForBurn` signature and resolves real, published contract addresses — but this hasn't been exercised against a live Arc CCTP contract yet. There's also an open, unresolved public report (as of 2026-09-18) that Circle's public Iris attestation API doesn't return attestations for Arc Testnet's domain 26 ([circlefin/evm-cctp-contracts#110](https://github.com/circlefin/evm-cctp-contracts/issues/110)) — verify attestation retrieval works before relying on this in production. `CCTP_ATTESTATION_API_URL` has no default for this reason.
</Callout>

## Starting a transfer

```python
from decimal import Decimal
from arc_devkit.bridge import CCTPBridge
from arc_devkit.core.connection import get_web3

bridge = CCTPBridge(w3=get_web3(), network="testnet")  # or "mainnet"

transfer = bridge.start_transfer(
    amount_usdc=Decimal("10.0"),
    recipient="0xRecipientOnOtherChain",
    destination_domain=0,       # destination chain's CCTP domain
    dest_chain_id=1,
    private_key="0xYourKey",
)
print(transfer.status)   # BridgeStatus.BURNED or FAILED
```

## Tracking and resuming

```python
from arc_devkit.bridge import load_transfer

transfer = load_transfer(transfer.id)

# Resume from the last known status (error recovery)
transfer = bridge.resume(transfer, dest_w3=dest_w3, message_transmitter_address="0x...", private_key="0x...")
```

Transfer records (`BridgeTransfer`) persist to `~/.arc_devkit/bridge_transfers/<id>.json`.

## Guardrails

```python
from arc_devkit.agents.guardrails import Guardrails

bridge = CCTPBridge(w3=get_web3(), network="testnet", guardrails=Guardrails.from_settings())
```

Applies the same daily-spend/whitelist/kill-switch checks as `PaymentAgent`.

## Monitoring completion

```python
from arc_devkit.agents.monitor_agent import MonitorAgent

monitor = MonitorAgent(watched_address="0x...", watch_bridge_transfers=[transfer.id])
monitor.on_bridge_completed(lambda evt: print("Bridge complete!", evt))
```

## CLI

```bash
arcdevkit bridge send 0xDest... 5.0 --dest-domain 0 --dest-chain-id 1
arcdevkit bridge status <transfer_id>
arcdevkit bridge resume <transfer_id> --dest-rpc https://... --message-transmitter 0x...
```

## REST API

```bash
curl -X POST http://localhost:8000/bridge/transfer -d '{...}'
curl http://localhost:8000/bridge/status/<transfer_id>
```

## Possible statuses

| Status | Description |
|---|---|
| `PENDING_BURN` | Not started yet |
| `BURNED` | Burn confirmed on Arc |
| `PENDING_ATTESTATION` | Waiting for Circle's attestation |
| `ATTESTED` | Attestation obtained — ready to mint |
| `PENDING_MINT` | Mint in progress on the destination chain |
| `COMPLETE` | Transfer complete |
| `FAILED` | Failed — see the `error` field |
