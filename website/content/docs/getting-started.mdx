## Requisitos

- Python **3.11** ou superior
- pip / pipenv / uv
- Uma chave de provedor de IA para o Dev Copilot — Anthropic (padrão, [obtenha em console.anthropic.com](https://console.anthropic.com)), ou Google Gemini / OpenAI / um servidor Ollama local
- Nenhuma configuração de RPC necessária para começar — Arc Mainnet e Arc Testnet já vêm com RPCs padrão oficiais

## Instalação

```bash
pip install arc-devkit
```

Para instalar com dependências de desenvolvimento (pytest, ruff, mypy):

```bash
pip install arc-devkit[dev]
```

Ou clone e instale localmente:

```bash
git clone https://github.com/Jeielsantosdev/arc_dev_kit.git
cd arc_dev_kit
pip install -e ".[dev]"
```

## Configuração

O Arc DevKit lê configurações de variáveis de ambiente ou de um arquivo `.env` na raiz do projeto.

### Wizard interativo

```bash
arcdevkit init
```

Isso abre um wizard que cria o arquivo `.env` passo a passo.

### Manual

Copie o arquivo de exemplo e preencha suas chaves:

```bash
cp .env.example .env
```

```bash
# .env
ANTHROPIC_API_KEY=sk-ant-...      # obrigatório (quando COPILOT_PROVIDER=anthropic, o padrão)

# Opcionais — o padrão é mainnet; defina testnet para desenvolvimento.
# RPC/chain ID já vêm pré-configurados por rede — só sobrescreva para usar
# seu próprio provedor.
ARC_NETWORK=testnet               # ou mainnet (padrão do SDK)
ARC_RPC_URL=
ARC_CHAIN_ID=
ARC_PRIVATE_KEY=0x...             # para enviar transações
ANTHROPIC_MODEL=claude-sonnet-4-6
LOG_LEVEL=INFO
API_KEY=                          # para autenticar a REST API
```

<Callout type="warning" title="Segurança">
  Nunca commit o arquivo `.env` no git. Adicione-o ao `.gitignore`. A chave privada (`ARC_PRIVATE_KEY`) é necessária apenas para operações de escrita. A Arc Mainnet é o padrão do SDK — se `ARC_NETWORK` não for definido, qualquer transação enviada gasta USDC real. Defina `ARC_NETWORK=testnet` durante o desenvolvimento.
</Callout>

## Verificando a conexão

```bash
arcdevkit status
arcdevkit doctor
```

Saída esperada:

```
Arc Mainnet
Chain ID:      5042
Current block: #21500000
Gas price:     0.02 gwei

⚠ Real funds — mainnet
```

`arcdevkit doctor` roda um health check completo: alcançabilidade do RPC, chain ID, bloco mais recente, latência e presença do contrato USDC.

## Primeiros passos

### Perguntar ao Dev Copilot

```bash
arcdevkit ask "Como funciona o gas em USDC na Arc?"
```

### Criar uma carteira

```bash
arcdevkit wallet create
```

### Verificar saldo

```bash
arcdevkit wallet balance --address 0xSuaCarteira
```

### Debugar uma transação

```bash
arcdevkit debug tx 0xSeuTxHash
```

## Variáveis de ambiente

| Variável | Obrigatória | Padrão | Descrição |
|---|---|---|---|
| `ANTHROPIC_API_KEY` | Se `COPILOT_PROVIDER=anthropic` | — | Chave da API Anthropic |
| `COPILOT_PROVIDER` | Não | `anthropic` | `anthropic` \| `gemini` \| `openai` \| `ollama` |
| `ARC_NETWORK` | Não | `mainnet` | `mainnet` ou `testnet` — define os defaults de RPC/chain ID/contratos |
| `ARC_RPC_URL` | Não | default da rede | Override da URL do RPC Arc (vírgula para múltiplos) |
| `ARC_PRIVATE_KEY` | Não | — | Chave privada para transações |
| `ANTHROPIC_MODEL` | Não | `claude-sonnet-4-6` | Modelo Claude |
| `ARC_CHAIN_ID` | Não | default da rede | Override do chain ID |
| `LOG_LEVEL` | Não | `INFO` | Nível de log |
| `API_KEY` | Não | — | Autenticação da REST API |

<Callout type="info" title="Multi-RPC Failover">
  Você pode passar múltiplas URLs de RPC separadas por vírgula em `ARC_RPC_URL`. O SDK usa fallback automático em caso de falha de rede.
</Callout>
