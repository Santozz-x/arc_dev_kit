## What the session shows

1. `python3 --version` — Python 3.14.7
2. `python3 -m venv .venv` + `source .venv/bin/activate` — a brand new, empty virtual environment
3. `pip install arc-devkit==0.10.0` — the real package, from the real PyPI (not a local build)
4. `python3 -c "import arc_devkit; print(arc_devkit.__version__)"` → `arc-devkit 0.10.0`
5. `python3 -c "import arc_devkit.client; print(arc_devkit.client.__file__)"` — proves the import resolves to the venv's `site-packages`, not a local checkout
6. `python3 mainnet_demo.py` — connects to Arc Mainnet, runs the health check, reads the latest block, auto-finds a confirmed transaction in the last 30 blocks, prints its full details (hash, status, block, USDC cost, decoded ERC-20 Transfer log), and runs the debugger with `use_ai=False`

**Transaction used in this recording:** `0x66805e7addc8884e80260a7a4abfad144f37341cd323b3327e93ea2cfbc23ceb`, block `#21,537,082`. Verify independently: <https://explorer.arc.io/tx/0x66805e7addc8884e80260a7a4abfad144f37341cd323b3327e93ea2cfbc23ceb>

## Isolation

Recorded with `env -i` (empty environment) and a throwaway `$HOME` under `/tmp` — no personal `.env`, shell history, dotfiles, or credentials were readable from inside the recorded process. Checked directly against the `.cast` file for leaked secrets/paths before publishing (see `docs/mainnet/MAINNET_DEMO.md` for the verification command used).

## Methodology (full transparency)

This session was executed by an automation script (`session.sh`), not typed live by a human, because it was produced by an AI coding agent rather than recorded at a human's keyboard. Every command in `session.sh` is real and was actually executed — `asciinema rec` captured the literal terminal input/output of that execution, including the real `pip` download, the real installed package, and the real RPC responses from Arc Mainnet. Nothing in the `.cast`/video is staged, mocked, or edited output. The only post-processing applied was `asciinema`'s own `--idle-time-limit 2`, which caps recorded idle gaps (e.g. between commands) at 2 seconds — it does not remove, reorder, or alter any command or its output.
